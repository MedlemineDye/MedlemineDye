## 📐 Les maths dans ma vie quotidienne

| Situation | Outil mathématique |
|---|---|
| Comparer deux offres ou promotions | Pourcentages et proportionnalité |
| Épargner ou rembourser un prêt | Intérêts composés, suites géométriques |
| Estimer un risque ou une chance | Probabilités |
| Analyser mes dépenses | Moyenne, écart-type, régression |
| Planifier un trajet ou des ressources | Optimisation |
| Cuisiner pour N personnes | Règle de trois |

Exemple : la valeur future d'une épargne avec intérêts composés.

$$
V = C \left(1 + \frac{r}{n}\right)^{nt}
$$
